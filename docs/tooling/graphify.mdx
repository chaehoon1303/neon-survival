Graphify는 저장소의 코드를 로컬 지식 그래프로 변환한다. 결과는 `graphify-out/`에 생성되며 Git에는 포함하지 않는다. 이 프로젝트의 기본 명령은 API 키 없이 재현할 수 있도록 코드 전용 분석을 사용한다.

## 요구 사항과 설치

Graphify는 Python 3.10 이상이 필요하다. 권장 설치 방법은 다음과 같다.

```bash
uv tool install graphifyy
graphify install
```

`uv`가 없다면 `pipx install graphifyy`를 사용할 수 있다. 설치 후 확인한다.

```bash
uvx --from graphifyy graphify --help
```

## 그래프 생성

```bash
npm run graph:build
```

이 명령은 저장소 전체를 분석해 다음 산출물을 만든다.

- `graphify-out/graph.html`: 대화형 그래프
- `graphify-out/GRAPH_REPORT.md`: 아키텍처 보고서
- `graphify-out/graph.json`: CLI/MCP용 데이터

코드가 바뀐 뒤에는 증분 갱신을 사용한다.

```bash
npm run graph:update
```

## 활용

```bash
uvx --from graphifyy graphify query "전투 모드가 핵심 루프를 어떻게 확장하는가?"
uvx --from graphifyy graphify path "beginSelectedMode" "spawnEnemy"
uvx --from graphifyy graphify explain "localStorage"
```

그래프는 탐색을 돕지만 구현의 확정 기준은 아니다. 결론은 실제 코드와 `GAME_SPEC.md`에서 확인한다.
