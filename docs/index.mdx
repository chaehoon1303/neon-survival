## 문서의 기준

- 게임 디자인의 확정 기준은 저장소 루트의 `GAME_SPEC.md`다.
- 작업 규칙은 `AGENTS.md`다.
- 이 사이트는 실행법과 코드 구조를 설명한다.
- 동작을 바꾼 커밋은 관련 문서도 같은 변경에서 갱신한다.
