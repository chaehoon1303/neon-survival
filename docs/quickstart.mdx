## 요구 사항

- Node.js 18 이상
- Python 3 (`http.server` 실행용)
- iOS 패키징 시 Xcode와 CocoaPods

## 웹 실행

```bash
npm run dev
```

`http://localhost:8080`을 열면 된다. 파일을 직접 여는 대신 로컬 HTTP 서버를 사용하는 이유는 브라우저의 로컬 파일 제한과 모바일 환경 차이를 줄이기 위해서다.

## 처음 플레이하기

1. 첫 실행 시 지급되는 100코인으로 무기 상자를 연다.
2. 장비 화면에서 획득한 무기를 장착한다.
3. 전투 탭에서 열린 맵을 선택한다.
4. `WASD` 또는 화면 조이스틱으로 이동한다.

주무기는 마지막 이동 방향으로 자동 공격한다. 마우스 조준은 사용하지 않는다.

## 빠른 검증

```bash
npm run check
```

자세한 작업 흐름은 [개발 가이드](/docs/development)를 참고한다.
