## 호환성 규칙

키 이름이나 값의 형태를 즉시 바꾸지 않는다. 스키마 변경이 필요하면 기존 값을 읽어 새 형태로 변환하는 일회성 마이그레이션을 먼저 추가하고, 변환 실패 시 안전한 기본값을 사용한다.

기존 `neonInventory`/`neonEquipped` 데이터에는 첫 장비 화면 렌더링 시 `instanceId`가 자동 부여된다. 장착 장비는 보유 목록에서 제거하지 않으며, 이 ID로 정확한 항목 하나에만 `착용 중` 상태를 표시한다.

머리 모듈은 기존 슬롯 데이터를 바꾸지 않고 `neonEquipped` 객체의 선택적 `head` 속성으로만 추가한다. 지원하지 않는 이전 빌드는 이 속성을 무시하므로 기존 장비 데이터와 충돌하지 않는다.

개발자 도구에서 사이트 데이터를 지우면 진행도가 초기화된다. 테스트 전에 필요한 저장값을 별도로 백업한다.
